# Security policy

## Reporting a vulnerability

Please report it privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue or pull request for it, and do not post details in discussions or chat.

Include what you found, the version, and steps to reproduce. We will acknowledge the report and keep you posted on the fix.

## Supported versions

Only the latest release is supported. Fixes land there and are not backported.
